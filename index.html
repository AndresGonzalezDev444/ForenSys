ACERCA DE

La Suite ForenSys

La suite ForenSys aborda los problemas identificados mediante las siguientes soluciones tecnológicas:

ForenSys Vision

Permite la vigilancia inteligente mediante reconocimiento facial en tiempo real, comparando rostros detectados con una base de datos criminal y generando alertas automáticas ante coincidencias relevantes. Esto fortalece la prevención y la detección temprana de riesgos mediante tecnología de redes neuronales profundas (YuNet DNN) que supera a los métodos clásicos de detección en precisión, velocidad y capacidad de identificar rostros en múltiples ángulos simultáneamente.

ForenSys Lab

Funciona como un módulo forense y biométrico para el análisis posterior de evidencias, incorporando lectura de huellas dactilares, coincidencia biométrica y perfilación estadística como apoyo a la investigación judicial. Está diseñado para integrarse fluidamente con los datos capturados por Vision, creando una cadena de custodia digital completa e inviolable.

⬡

Ambos módulos comparten una estructura de datos unificada, lo que facilita la interoperabilidad, la trazabilidad de la información y la reutilización de evidencias dentro del ecosistema ForenSys. Esta arquitectura garantiza que cada pieza de información recopilada por Vision sea inmediatamente accesible para el análisis profundo en Lab, eliminando silos de datos y acelerando los procesos de investigación.

Principios de Diseño

  • 01
    Precisión sobre velocidad

    Cada módulo privilegia la exactitud biométrica, reduciendo al mínimo los falsos positivos que podrían comprometer investigaciones.

  • 02
    Privacidad por diseño

    Los datos biométricos se procesan localmente. Ninguna imagen o identificador abandona la red interna del organismo operador.

  • 03
    Interoperabilidad total

    Base de datos SQLite unificada con API REST estándar, facilitando integraciones futuras con sistemas existentes.

TECNOLOGÍA

Stack Técnico

ForenSys utiliza un conjunto de tecnologías open-source de alto rendimiento, seleccionadas por su precisión, velocidad y fiabilidad en entornos críticos.

CV

OpenCV 4.13

Motor de visión artificial. Integra el detector neuronal YuNet (FaceDetectorYN) para identificación multi-ángulo en tiempo real, superando los métodos Haar Cascade convencionales.

Core Engine
FA

FastAPI

Framework web asíncrono de alto rendimiento en Python. Expone la API REST que conecta el backend de análisis con el dashboard web, con soporte a WebSockets para streaming en tiempo real.

API Layer
ML

LBPH Recognizer

Algoritmo Local Binary Patterns Histograms de OpenCV para reconocimiento e identificación de individuos. Opera sobre las regiones de interés extraídas por YuNet con alta eficiencia computacional.

Biometría
DB

SQLite + SQLAlchemy

Persistencia de datos con modelo relacional unificado. Almacena sospechosos, fotografías biométricas por ángulo, alertas generadas y perfiles conductuales en una sola base de datos portátil.

Persistencia
NM

Nmap + Scapy

Módulo CamHunter integra escaneo de red activo (Nmap), captura de tráfico (Scapy) y fuerza bruta RTSP para auditoría profesional de infraestructuras de cámaras IP en entornos corporativos.

Auditoría de Red
Py

Python 3.14

Lenguaje base del ecosistema. Gestión de hilos para video sin bloqueo de interfaz, compatibilidad con entornos Windows y arquitectura modular que facilita la extensión de funcionalidades.
